3. 수집·처리 방법과 선택권

  • Google 로그인·연동 동의, 이용자의 직접 입력·파일 선택, 승인된 학교 공유 자료 조회와 외부 API 통신을 통해 처리합니다.
  • 학교 계정 로그인과 Calendar·Tasks·Drive 연결은 별도 절차입니다. 동의하지 않으면 해당 연동 기능이 제한될 수 있습니다.

  • QR 생성은 PC 안에서 처리하지만, QR을 다른 사람에게 전달하거나 연결 사이트를 열면 해당 내용·접속정보가 외부에 전달될 수 있습니다.
  • Google 비밀번호를 앱의 입력란에서 수집·저장하지 않습니다. Google 인증 화면에서 로그인합니다.

4-1. 학교 자료의 항목별 접근 권한

학교 승인과 개인정보 열람 권한을 따로 확인합니다. 교직원의 학생 기본 열람 범위는 학번·이름·사진이며, 교직원 기본 열람 범위는 이름·내선번호입니다. 관리자는 학생 상세정보, 학생·보호자 연락처, 교직원 비상연락처를 각각 필요한 계정에 부여·해제합니다. 권한이 없는 기능·항목은 숨기고 조회 요청을 제한하며, 해당 권한의 상세 파일 식별자를 제공하지 않습니다. 구매처·시건장치의 관리용 보안자료는 관리자에게 제한합니다.

기존 전체 공유 자료를 사용하는 학교는 관리자가 개인정보 자료 분리 · 공유 권한 점검을 실행해 기본 자료·학생 상세정보·학생 연락처·교직원 연락처 파일을 분리하고 기존 파일 공유를 축소해야 합니다. 학교별 완료 상태는 관리자가 직접 확인합니다. 분리 준비가 끝나지 않은 자료를 교직원에게 기존 전체 파일로 대신 제공하지 않습니다.

수업 진도·학생 행동관찰·상담·누가기록은 작성한 교사 본인만 조회하고 다른 교사에게 자동 공유하지 않습니다. 수업·관찰 백업과 기존 상담·누가기록 백업은 각각 해당 기능에서 저장·복원합니다. 학생 상세정보 권한이 다른 교사의 상담기록 열람 권한을 뜻하지 않습니다. 위젯 배치 동기화에도 기록 내용이 포함되지 않습니다.

4-2. Google 사용자 데이터의 Limited Use 준수 / Limited Use compliance

선부 ON은 Google Workspace API에서 받은 원본·집계·파생 사용자 데이터의 이용과 다른 앱·서비스로의 전송에 Google API Services User Data Policy와 Google Workspace API User Data and Developer Policy의 Limited Use 요건을 적용하고 준수합니다.

해당 데이터를 기반 모델 또는 범용 AI·ML 모델의 생성·학습·개선 목적으로 사용하거나, 그러한 목적으로 제3자 AI 서비스 등에 전송·제공·판매하지 않습니다. 원본뿐 아니라 집계·요약·비식별 처리·기타 파생 데이터에도 같은 제한이 적용됩니다. 단순한 사용자 동의가 이러한 금지 용도를 허용하는 것은 아닙니다.

Google API 자료는 안내한 이용자 기능에 필요한 범위에서 처리합니다. 캘린더·할 일·Drive의 API 조회 결과를 Gemini 요청에 자동으로 불러오거나 첨부하지 않습니다. 외부 AI 입력에 관한 허용 범위와 이용자 주의사항은 5절을 따릅니다.

Google Workspace API data — Limited Use compliance statement

Seonbu ON's use and transfer of raw, aggregated, or derived user data received from Google Workspace APIs adhere to the Google API Services User Data Policy and the Google Workspace API User Data and Developer Policy, including the Limited Use requirements.

We do not use, transfer, provide, or sell this data to create, train, or improve foundational or generalized AI or machine-learning models, including through third-party AI services. These restrictions also cover summaries and other derived or de-identified data. User consent does not authorize these prohibited uses. Google API data is used for the disclosed user-facing features; API-fetched Calendar, Tasks, and Drive data is not automatically retrieved or attached to Gemini requests.

5. AI 기능의 외부 전송

공문·품의 다듬기, 부서 원문 요약·일정 후보 만들기, 관련공문 캡처의 문서번호·날짜 추출을 실행할 때 전송 확인 창을 표시합니다. 확인한 작성란·부서 원문 텍스트 또는 사용자가 붙여넣거나 선택한 캡처 이미지와 기능 수행 지시를 사용자의 API 키로 Google Gemini API에 보냅니다. 캡처 이미지는 추출 요청을 위한 메모리에서 처리하며 별도 이미지 파일로 자동 저장하지 않습니다. 요약·일정·문서번호·날짜는 사용자가 검토한 뒤 적용합니다. 학교 연락망·학생 사진·수업 진도·상담·관찰기록을 자동 첨부하지 않습니다. 캘린더 AI에는 날짜 없는 입력과 상대 날짜 표현도 사용할 수 있으며, 매주 일정은 이용자가 기준일·요일·시작일·종료일과 생성 날짜를 확인한 뒤 반영합니다. 이용자가 직접 입력·붙여넣기·선택한 텍스트나 이미지에 개인정보가 포함되어 있으면 함께 전송될 수 있습니다.

AI 입력에 Google API 자료를 넣지 마세요. Google API로 받은 일정·할 일·Drive 파일 등과 그 집계·요약·파생 자료를 Gemini 작성란에 복사·붙여넣거나 캡처 이미지로 넣어 전송하는 것은 허용하지 않습니다. 일반적인 AI 전송 동의나 개인정보 제거만으로 이 제한이 해제되지 않습니다. 학습 제외 조건이 확인되지 않은 외부 AI 서비스에 Google API 자료를 제공하는 것도 허용하지 않습니다.

9. Google 사용자 데이터의 보호조치

  • 전송 중 보호: Google 계정 인증·토큰 교환·Calendar·Tasks·Drive API와 학교 인증·공유 서버 통신은 HTTPS를 사용합니다. 데스크톱 OAuth의 일회성 콜백은 이 PC의 127.0.0.1에만 바인딩하며 state 검증과 PKCE를 사용합니다.

Protection of Google user data

Seonbu ON uses HTTPS for communication with Google authentication and Google APIs. OAuth uses PKCE and a validated state parameter, with a temporary loopback callback bound to 127.0.0.1 on the user's PC. Calendar and Tasks access and refresh tokens are encrypted at rest using Electron safeStorage backed by Windows security facilities; if secure storage is unavailable, these tokens are not saved in plaintext. The app does not collect or store Google passwords. School membership and role checks restrict shared school data, and Calendar/Tasks writes are checked against the connected Google account. Not all local preferences, calendar/task display caches, exported files or user-made copies are encrypted. Users control those copies. Disconnecting removes the local Calendar/Tasks token file and attempts revocation, but does not delete original Google events or tasks. Users may also revoke access at myaccount.google.com/connections and request deletion at chun87@goedu.kr. Google data is used only for user-facing features, not sold, used for advertising, or used to develop, improve or train generalized AI or ML models.

연동 통신에 HTTPS를 사용하고, Google OAuth 인증, 학교 승인·역할 확인, 자동 화면 잠금 및 Windows 보안 저장 기능을 사용합니다. 로그인 토큰·학교 자료 캐시·보호된 연락망·도구상자 자료 등은 보안 저장 대상으로 구현되어 있습니다. 모든 PC 설정·캐시·출력물이 암호화되는 것은 아닙니다. 공용 PC에서 잠금·로그아웃을 확인하고 Windows 계정·출력 파일을 관리하세요.

공개 안내서와 설치 배포물에 실제 학교 자료를 포함하지 않으며, 안내서 캡처에는 가상 자료를 사용합니다. 안내서의 사용 확인 체크 상태는 해당 브라우저 로컬 저장소에 저장됩니다. 선택한 위젯과 학교 자료를 화면에 표시하는 동안 다른 사람에게 노출되지 않도록 주의하세요.
